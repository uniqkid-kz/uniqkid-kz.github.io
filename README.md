# UNIQKID catalog site

Статический каталог, готовый для GitHub Pages.

## Публикация

1. Загрузите содержимое этой папки в корень репозитория GitHub.
2. Откройте **Settings → Pages**.
3. Выберите публикацию из ветки `main`, папка `/ (root)`.
4. Сохраните настройки и дождитесь появления адреса сайта.

Локальный просмотр требует HTTP-сервера, потому что каталог загружается из `data/products.json`.

## Состав

- `index.html` — главная страница в фирменной красной стилистике;
- `assets/logo.svg` — логотип UNIQKID;
- `styles.css` — адаптивное оформление для компьютера и телефона;
- `app.js` — поиск, четыре главных раздела, подкатегории, сортировка, галерея и карточка товара;
- `data/products.json` — отфильтрованный каталог только по утверждённым направлениям.

Изображения загружаются с CDN Kaspi. Цены и наличие могут меняться, поэтому каждая карточка содержит прямую ссылку на Kaspi.
